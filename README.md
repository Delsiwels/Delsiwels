# Hi, I'm Delsi Sierra

I’m a Bookkeeper Manager and accounting operations leader working with
Australian companies, building practical tools at the intersection of
accounting operations and AI.

## What I’m building

**[FinQL](https://finql.ai)** is an AI-assisted workflow platform for
Australian accounting, BAS, GST, payroll, bookkeeping, and finance teams. It
combines deterministic checks with human review, audit trails, and guarded
automation so practitioners can move faster without losing professional
judgement.

My current focus is applying accounting context to AI support, product
operations, workflow design, and trustworthy automation.
